# Verdade ou Desafio

Este projeto é um jogo de **Verdade ou Desafio** desenvolvido como um projeto antigo, criado durante o período do meu ensino médio.

Mesmo sendo uma aplicação simples, ele se destaca principalmente pelo seu alto nível de **customização**, permitindo que os jogadores adaptem a experiência de acordo com suas próprias regras, categorias e estilos de jogo.

---

## Destaques do projeto

- Jogo clássico de Verdade ou Desafio
- Sistema altamente personalizável
- Possibilidade de criar diferentes modos de jogo
- multiplayer local)
- Interface simples e funcional focada na experiência do jogador

---

## Sobre o projeto

Este projeto foi desenvolvido com foco em aprendizado prático de lógica de programação e interação com o usuário. Ele representa uma fase inicial de desenvolvimento, onde o objetivo principal era explorar criatividade e funcionalidades em jogos simples.

---

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript (Vanilla)

---

## Observação

Por ser um projeto antigo, ele não segue padrões avançados de arquitetura ou design modernos, mas representa um importante passo no processo de aprendizado e evolução como desenvolvedor.
